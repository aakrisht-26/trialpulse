# Development checks of the served scores

Research demo. Not medical advice. Not for patient decision-making.

This file is generated by `uv run python -m trialpulse.scoring.checks` (CLAUDE.md Step 13, ADR 0034). Do not edit it by hand. These are development checks on the 2016 and 2017 origins: development evidence about how the served scores are computed, kept outside the registered results ([results.md](results.md), ADR 0032).

- **Source:** [ClinicalTrials.gov](https://clinicaltrials.gov) registry records, through the version-history dataset `brbk/clinical_trials_history` (license CC-BY-NC-4.0), revision v2026.09.26. Data as of 2026-09-25. TrialPulse normalizes the records and derives every number here; these are not part of ClinicalTrials.gov (ADR 0008).
- **Models:** the development champions (M4 at each origin), fitted again and used because they reproduce every score the development runs saved (2016-01-01: largest difference 0.0e+00, 2017-01-01: largest difference 0.0e+00).
