Generated by `uv run python -m trialpulse.warehouse.build` from the warehouse it builds (`data/warehouse.duckdb`). Counts only: no sponsor names and no free text. Part 2 (the cohort funnel and outcomes) comes with Step 4.

## Text normalization and personal data

The dataset stores most long texts as HTML with entities; API v2 returns Markdown. Both are reduced to the same plain text: one line per paragraph or list item, entities unescaped, Markdown escapes removed, email addresses replaced by a marker. Each text is stored once in `texts`, keyed by its SHA-256.

| --- | --- | --- | --- | --- |

| `official_title` | 693,416 | 0 | 3 | 0 |
